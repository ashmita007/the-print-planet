# Contactless RFID Smart Cards & Consumables

Secure credential badges for enterprise physical access control, attendance recording, transit, and campus micro-payments.

## Technical Specifications
- **Mifare 1K Classic (13.56 MHz):** ISO/IEC 14443 Type A compliant, 1KB EEPROM memory with 16 sectors, dual security keys, high gloss dye-sublimation receptive PVC face.
- **EM-Marin Proximity (125 kHz):** 64-bit factory read-only ID token, available in ISO thin printable card and rugged clamshell format.
- **Inkjet Printable Core Sheets:** Silica-coated A4 sheets for inkjet badge printing, fused to standard 0.76mm card thickness.
